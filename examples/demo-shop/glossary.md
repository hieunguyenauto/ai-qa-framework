# Glossary — demo-shop

| Term (as in the UI) | Meaning |
|---|---|
| Products | The product list shown after login (SHP02) |
| Add to cart / Remove | Button on each product; toggles between the two after a click |
| Cart badge | Number on the cart icon in the header = number of items in the cart; hidden when the cart is empty |
| Your Cart | Cart screen (SHP03) |
| Checkout: Your Information | Form with 'First Name', 'Last Name', 'Zip/Postal Code' (SHP04) |
| Checkout: Overview | Order summary with 'Item total', 'Tax', 'Total' (SHP05) |
| Checkout: Complete! | Order completed screen (SHP06) |
| Item total | Sum of the prices of the items in the cart (quantity is always 1) |
| Tax | 8% of Item total, rounded to 2 decimals (OQ-CHK-004) |
| Total | Item total + Tax |
| Back Home | Button on the Complete screen, returns to Products |
| Continue Shopping | Button on the cart, returns to Products |
| Logout | Item of the burger menu, returns to Login |
