| Technique | Use when | Coverage |
|---|---|---|
| EP — Equivalence partitioning | Input has valid / invalid groups | ≥ 1 TC per partition |
| BVA — Boundary value analysis | Min / max, length, thresholds | min-1, min, max, max+1 |
| Decision table | Several conditions combine into different results | ≥ 1 TC per rule |
| State transition | States + transitions | Every valid transition + important forbidden ones |
| Scenario / use flow | Multi-step business flow | Main flow + alternative flows |
| Role matrix | Permissions differ by role | Every role × action cell in the spec |
| Combination (pairwise) | Many independent parameters | Every pair of values appears ≥ 1 time |
| Error guessing | Errors known from experience | State the reason |
